## 📡 Wiiew

A Wi-Fi CSI-based room-presence sensing system built around the **RuView / ESP32 CSI ecosystem**.

Wiiew explores how changes in Wi-Fi Channel State Information can be used to detect whether a person is present within a defined environment.

### Highlights

* Wi-Fi CSI sensing
* ESP32 CSI node integration
* Room-presence detection
* Distance-based room boundary
* Local sensing backend
* FastAPI backend
* Web interface
* PWA-oriented frontend
* Real-time sensing pipeline

**Tech**

`ESP32` `Wi-Fi CSI` `Python` `FastAPI` `React` `JavaScript` `RuView` `PWA`

[Repository](https://github.com/shr3y4n/Wiiew)
